# Echo

The simplest possible app. Useful for testing the routing path end-to-end.

## Commands

- `/echo <message>` — The bot replies with exactly the message you sent.

## When to use

- Confirming the bot is up and routing slash commands correctly.
- Reproducing routing issues with a known-good handler.
- Verifying new infrastructure (e.g. permissions, rate limits) without touching real app data.
